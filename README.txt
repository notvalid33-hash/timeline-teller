Timeline Analyzer V2.3
=======================

Understand where you've been.
By Dinesh

V2.3
----
- New hamburger menu to keep the Overview screen clean.
- After Timeline.json loads, the front screen shows only Data coverage, Analyze a date range, and Summary.
- Travel dashboard with averages, modes, longest journey and busiest month.
- Personal travel records.
- On This Day comparison across years.
- Places: all places retained, first 5 shown, Show more, search, custom names, place insights and map actions.
- Routes: repeated-route grouping, clean representative-path highlighting, route insights and saved names.
- Map overview plus travel heatmap.
- Monthly distance/trip charts and travel mode breakdown.
- Monthly estimated fuel cost history.
- Timeline search by place, mode, date or distance (>50 km / over 50 km).
- Personal report generator with download and Print / Save PDF.
- Fuel calculator and daily reminder.
- Import / JSON guide remains available from the menu.
- V2.3 service-worker cache refresh.

Privacy
-------
Timeline.json is processed locally in the browser and is not uploaded to the GitHub site.
Map tiles require internet access.
Browser background notifications may be limited on Android; a native Android app is more reliable for exact daily delivery.
